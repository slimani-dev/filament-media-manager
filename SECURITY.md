# Security Policy

## Supported Versions

Only the latest version of Media Manager is supported for security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions or pull requests.

Report them privately instead, either through GitHub's
[private vulnerability reporting](https://github.com/slimani-dev/filament-media-manager/security/advisories/new)
or by emailing mohamed@slimani.dev.

Please include the affected version, a description of the issue and steps to reproduce it. You can expect an
acknowledgement within a few days. Fixes are released as a patch version together with a GitHub Security Advisory,
and reporters are credited unless they prefer otherwise.
